# 天賦圖示辨識度修正

- 目標／範圍：七職業天賦圖示在一般桌面與手機可辨識，不只把預設 55% 改為 85%。
- 證據／目標：web/app.mjs 的 renderTalentTree 預設 55%，一般節點 39.6px；扣除邊框／padding 的圖片只有 29.6px。法務官的 288px 圖片中央圖案約佔六成，周圍透明留白再次縮小圖案。
- 修改：預設 100%，縮放範圍 50–150%；圖示在節點內以 1.6 倍呈現並裁掉外圍留白，維持完整中央圖案。桌面樹畫面擴至 96rem，詳情欄 18–22rem；原始座標以等比例 1.25 倍顯示間距呈現，避免巢都渣滓 60px 相鄰方形節點重疊；連線、同頁詳情及手機樹內捲動不變。
- 驗證：此問題是 CSS 實際尺寸與佈局，單元測試無法證明辨識度。使用既有 browser-smoke 加入預設 100%、普通節點至少 70 CSS px 及全節點不重疊的回歸檢查，先 Red 再 Green。原有七職業圖示載入／連線／條列詳情／手機溢出檢查照常執行，Chrome 另目視法務官與歐格林。
- 交付：小幅獨立 PR，CI 成功後合併部署，正式站核對新 build 與圖示尺寸。若裁切個別素材的中央圖案，先調整顯示規則；必要時可回復整個介面提交。
- 不涉及：圖片檔修改、新來源擷取、遊戲資料或數值更新。

## 原圖外形修正

- 使用者要求外框依原圖呈現。固定圓形／方形外框來自節點類型 CSS，與圖片自己的外形無關。
- 在 web/style.css 中，已載入原圖的節點取消類型外框、背景與裁切，以透明素材自身呈現圓形／方形或其他形狀。hover／選取以原圖輪廓發光，缺圖替代節點與鍵盤焦點保留。
- 樣式的實際裁切無法由單元測試驗證；既有 browser-smoke 加入原圖不受遮罩／外框限制的檢查，先 Red 再 Green；原有七職業、圖示尺寸、連線、同頁詳情與手機檢查繼續執行。
- 原圖 URL／資料與 100% 預設縮放不變；無下載／改寫原圖、無像素分析或跨來源 canvas 相依。CI 通過後部署，正式法務官頁面核對圓底及方底素材。

- 圖片放大後的透明留白不接收點擊；互動保留在原有 button 範圍，避免超出節點的圖片矩形攔截相鄰節點。瀏覽器檢查一併驗證原圖為非互動子元素。
