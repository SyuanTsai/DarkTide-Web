# W06 review candidate

Run `npm run contract:w06:validate` to validate the pinned W06 inputs without writing files. To generate a local review candidate, pass `--out-root <new-directory>` to `node scripts/content/contract-w06.mjs`; the directory must not already exist, and its files are review-only outputs. W06 remains pending and ineligible for publication; the candidate does not change the shared release or deployment inputs.
