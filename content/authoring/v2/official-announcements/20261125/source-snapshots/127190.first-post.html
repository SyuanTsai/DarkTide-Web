This new layout has fewer grid points than previous ones, and there’s two nodes that we’re trying something different with! Grid Point Alpha has a single Scavenge Zone to go through, so it’s a more contained Expedition.

Grid Point Beta is unlocked by extracting from Grid Point Alpha with a sufficiently high amount of Tech-Remnants in a single Expedition. In turn, Node Beta is a much more intense Expedition that will test the mettle of all but the toughest members of the Warband!
