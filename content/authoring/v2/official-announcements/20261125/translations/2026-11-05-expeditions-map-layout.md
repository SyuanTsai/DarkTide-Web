# 遠征地圖配置更新

## 打擊小隊

遠征地圖已更新，換上全新配置！是時候重返荒原，再次闖過各個網格點了！

![遠征新地圖配置](https://europe1.discourse-cdn.com/flex013/uploads/fatshark/optimized/3X/4/3/43986a079c5b05da9091fa2bc15d0c632d0f2ff8_2_624x351.jpeg)

[原圖](https://europe1.discourse-cdn.com/flex013/uploads/fatshark/original/3X/4/3/43986a079c5b05da9091fa2bc15d0c632d0f2ff8.jpeg) · [下載原圖](https://forums.fatsharkgames.com/uploads/short-url/9DYxfTbjLLOyXzrEeYbgr91QEyc.jpeg?dl=1)

這次的新配置比以往的網格點更少，而且有兩個節點我們嘗試了不同的做法！**網格點 Alpha（Grid Point Alpha）**只需要通過一個搜刮區（Scavenge Zone），是一場範圍更集中的遠征。

在單次遠征中從網格點 Alpha 撤離時，若帶出的科技殘骸數量夠多，就會解鎖**網格點 Beta（Grid Point Beta）**。而節點 Beta 則是一場強度高得多的遠征，除了打擊小隊中最強悍的成員之外，所有人都會受到嚴峻考驗！
