Warband!

Hotfix 1.13.3 is now being rolled out on all platforms, and while you wait for it to download you can read the notes below!

This hotfix contains tons of bug fixes, as well as some tweaks to the Spillway end event and Expeditions.

Patch 1.13.3 patch notes

Features & Tweaks

  • Spillway End Event:
    • Bots now prioritize helping incapacitated players over participating in the fight against the Prophet of Decay in the Spillway mission.
    • The Prophet of Decay now has a constant damage zone around him during the circle phase. The damage zone matches the VFX previously in place.
    • Updated the VFX displayed when hitting the shield of the Prophet of Decay.
    • (Havoc) Weakened Monstrosities can no longer spawn for the duration of the event.
    • Specialist Surge Strikes can no longer occur during the event.
  • Expeditions: Players who disconnect when there is a rescue reward for them will now be replaced by a pickup near the respawn beacon containing the reward.
  • The Relic Blade Sprint Heavy Stab buff from held charge while sprinting can now also be triggered while dashing through the ‘Chastise the Wicked’ / ‘Fury of the Faithful’ Abilities.

Fixes

General Fixes

  • Removed the Penance related to Heretical Idols in the ‘Depths’ zone.
    • Dev Note: We are planning to add back this Penance in a future update that will add Heretical Idols to the Spillway mission.
  • Fixed an issue where Veteran’s ‘Executioner’s Stance’ Ability could not be refreshed by kills performed through sticky attacks (e.g. Special activated attacks with the Assault Chainsword).
  • Pack Master: Fixed an issue where all of their strikes would apply the Stamina and Dodge Reset debuff to players.
    • Now only attacks performed with their electrical maul will apply the debuff.
  • Scab & Dreg Vanguards: Fixed an issue where certain attacks caused an incorrect stagger reaction.
  • Expeditions:
    • Fixed an issue where Medicae Stations would fail to display their usage cost.
    • Fixed an issue where the Scrap amount displayed after hot joining would be incorrect.
  • Fixed an issue where flickering could be experienced when transitioning into the Prophet of Decay intro cutscene.
  • Fixed an issue where a red hitmarker would be displayed on every hit after already having killed the Prophet of Decay, before transitioning to the outro cutscene.
  • Fixed Companion nameplates not updating the name after a Personality Scourge.
  • Fixed an issue where the Skitarii ‘Power Drive’ upgrade talent for the ‘Overload’ Keystone sometimes could fail to give the correct amount of stacks after using the ‘Advanced Combat Doctrines’ Ability, if it had consumed all the available Capacitance charges in one use.
  • Fixed a rare crash that could happen if a player started spectating a Psyker just as the operative gained an amount of Peril.
  • Fixed a crash that could happen if a player exited a mission or the Meat Grinder while a smoke cloud effect was active (e.g. Veteran’s ‘Smoke Grenade’).
  • Fixed an issue where Corruption damage would fail to kill players that had a fully corrupted Health bar.
  • Fixed an issue where Zealot’s ‘Until Death’ talent could be triggered when receiving Corruption damage while at 1 Health point, even if the Health bar was otherwise not fully corrupted.
  • Fixed an issue where Psyker’s ‘Empyric Recovery’ Penance could not be completed.
  • Fixed an issue where Skitarii’s ‘Sicarian Disciple’ Penance could not be completed.
  • Fixed an issue where Skitarii’s ‘Advanced Combat Doctrines’ Ability could lock-on friendly players instead of enemies after having tried to use the Artificer Servo-Skull Blitz at 0 charges.
  • Fixed an issue where Skitarii’s ‘Chordclaw Strike’ Ability would play an incorrect sound effect.
  • Fixed an issue where stacks from the ‘Blaze Away’ and ‘Inspiring Barrage’ weapon Blessings could be reset when shooting in ADS stance with the Ogryn’s Thugshot weapon.
  • Fixed an issue where Ogryn’s ‘Lucky Bullet’ triggers from talents could reset the ‘Blaze Away’ weapon Blessing stacks for the Kickback and Thugshot weapon families.
  • Fixed an issue where Ogryn’s ‘No Stopping Me!’ talent would not be applied when charging the Heavy 2 attack on both Battle Maul & Slab Shield weapon marks.
  • Fixed an issue where an incorrect additional notification was displayed when reaching the max Mastery level for the Ogryn’s Battle Maul & Slab Shield weapon family.
  • Fixed an issue where the Mortis Trials Skitarii’s ‘Hard-Wired Reaction Boost’ buff would consume a larger than intended amount of Capacitance when triggered.
  • Fixed an issue where locked missions appeared as unlocked on the mission board.
  • Fixed an issue where players would be blocked from matchmaking if a Strike Team member changed operatives at a specific timing.
  • Fixed some potential frame drops when using the Emote Wheel or Communication Wheel if DLSS is enabled.
  • The Audio Devices list is now properly evaluated when changed and is updated in the audio settings.
  • Fixed a crash for RDNA3 users running WIndows 10. The game crashed when starting the game with FSR 3.1 enabled from launcher or FSR 4.1.1 ingame.
  • Potential fix for users on CPU’s not having full AVX/AVX2 support.

Cosmetic Fixes

  • Fixed a minor issue where the Vostroyan Flak Coat with Psykana Collar had inconsistent shoulder pads.
  • Fixed an issue where the Athonian 98th Fatigues sleeves clipped with the vambraces.
  • Fixed an issue where the muzzle of Ursula’s Hope would not heat up visually.
  • Fixed a material issue where metal parts was displayed incorrectly on Brute Model Cranial Implant (XXXXL), Commemorative head screws, and Cranial-Coolant Implant.
  • Fixed an issue where Tanker Commander’s Battlegear Cadian 802nd unintentionally changed colour - we restored the item to use the original colour again.
  • Fixed an issue where Mordian Cleric Jacket intersected with many lower body cosmetics.

Known Issues

  • Scab and Dreg Vanguard enemies currently have slightly more health than intended.

That’s all for today!

We’ll see you on the Mourningstar.
